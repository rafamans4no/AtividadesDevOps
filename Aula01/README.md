## Conteúdo apresentado

### Introdução ao Versionamento e Deploy
A disciplina de Programação Web trabalha a construção de interfaces e o desenvolvimento de aplicações. Junto com o conteúdo de Deploy, aprendi que é possível fazer o versionamento, registro e monitoramento das versões de um projeto com muito mais facilidade. Isso permite:

- Recuperar versões específicas;
- Trabalhar de forma colaborativa;
- Automatizar processos;
- Realizar o deploy;
- Ter controle de versões.

### Automação de Pipelines (CI/CD)
Entendi que um pipeline é a sequência automatizada de tarefas que vai desde o desenvolvimento até a disponibilização da aplicação. Com ele, atividades repetitivas podem ser otimizadas, reduzindo o retrabalho e evitando que falhas passem despercebidas.

### Integração Contínua (CI)
A Integração Contínua é a prática de integrar frequentemente as alterações feitas pelos desenvolvedores. Cada alteração dispara automaticamente processos de compilação e testes, o que ajuda a identificar bugs e problemas logo no início do desenvolvimento.
### Qualidade de Software e Testes Automatizados
A qualidade do projeto precisa ser validada durante todo o processo de desenvolvimento. Para isso, existem ferramentas de automação que analisam:

- Padronização do código;
- Segurança;
- Complexidade;
- Cobertura de testes;
- Vulnerabilidades.

### Entrega Contínua (CD)
Depois que as alterações são aprovadas nos testes e estão funcionando corretamente, elas seguem para a etapa de deploy, trazendo benefícios como:

- Redução do tempo de entrega;
- Maior estabilidade das aplicações;
- Menor risco durante as implantações.

### Containers e Estratégias de Implantação
Os containers servem para padronizar ambientes. Isso resolve um problema comum: uma tecnologia pode se comportar de forma diferente dependendo do dispositivo ou ambiente. Com o container, a aplicação funciona da mesma forma independente da máquina, seja em desenvolvimento, teste ou produção.
